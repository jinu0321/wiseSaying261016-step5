# 명언 앱 1~5단계

[기존 저장소의 5단계 커밋](https://github.com/jinu0321/wiseSaying261016/commit/bee70b1)을 바탕으로 만든 제출용 저장소입니다.

Java 내장 기능만 사용합니다. `Quote` 클래스에 번호, 내용, 작가를 저장하며 등록할 때 번호를 1씩 늘리고 목록은 최신순으로 출력합니다.

## 실행

JDK 17 이상에서 저장소 루트에서 실행합니다.

```sh
mkdir -p out
javac -encoding UTF-8 -d out src/main/java/org/example/Main.java
java -cp out org.example.Main
```

명령은 `등록`, `목록`, `종료`입니다. 등록할 때 명언, 작가 순서로 입력합니다.

## 검증

- Java 17 호환 문법으로 컴파일
- 시작 문구와 명령 프롬프트, 종료
- 명언·작가 등록과 등록 번호 안내
- 여러 번 등록할 때 번호 증가
- 목록 헤더와 구분선, 최신순 출력
- 번호·내용·작가를 가진 `Quote` 클래스
- 외부 라이브러리 없이 컴파일·실행

빈 목록, 한 건 등록, 여러 건 등록, 목록 조회 후 추가 등록, 입력 종료도 함께 확인했습니다.
